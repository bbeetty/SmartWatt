# SmartWatt — UI Design（介面設計）

> SDD Stage 1.5 · `design.md` — 回答「畫面長什麼樣子」。搭配 `spec.md` 定需求、`plan.md` 定架構，三份文件共同描述完整系統。

---

## 1. Design Principles

| 原則 | 說明 |
|------|------|
| **資料優先** | 每個頁面的主要目的是讓數字容易閱讀，不過度裝飾 |
| **一致性** | 全站使用 Ant Design 元件與設計語言，不自製重複元件 |
| **漸進揭露** | 主要功能一眼可見；細節（帳單明細、計費說明）以 Modal / Tooltip 揭露 |
| **可操作性** | 所有 CRUD 操作從列表頁直接完成，不跳轉另一頁 |

## 2. Design Tokens（Ant Design 主題覆寫）

```ts
// apps/web/src/theme.ts
export const themeToken = {
  token: {
    colorPrimary:    '#1677ff',   // AntD 預設藍（保留）
    colorSuccess:    '#52c41a',   // 節能達標、正向數字
    colorWarning:    '#faad14',   // 用電偏高提示
    colorError:      '#ff4d4f',   // 超出預算
    borderRadius:    8,
    fontSize:        14,
    fontFamily:      '"Noto Sans TC", "PingFang TC", sans-serif',
  },
  components: {
    Layout: {
      siderBg:       '#001529',   // AntD 深色 Sider 預設
      triggerBg:     '#002140',
    },
    Statistic: {
      titleFontSize: 13,
    },
  },
};
```

### 語意色彩使用規範

| 情境 | Token | 顏色 |
|------|-------|------|
| 用電量、度數 | `colorPrimary` | 藍 |
| 電費金額 | `colorWarning` | 橙黃 |
| 碳排量 | `colorSuccess` / `colorError` | 綠（低）/ 紅（高） |
| 刪除操作 | `colorError` | 紅 |

## 6. Responsive Breakpoints

| Breakpoint | 範圍 | 佈局變化 |
|------------|------|----------|
| `xs` | < 576px | 隱藏 Table 次要欄；KPI 卡 2×2 |
| `sm` | 576–767px | 同上 |
| `md` | 768–991px | Sider 改 Drawer；KPI 卡 2×2 |
| `lg` | 992–1199px | Sider 展開；KPI 卡 4×1 |
| `xl` | ≥ 1200px | 標準 Desktop 版型 |

AntD 的 `Col span` 範例（KPI 卡）：
```tsx
<Col xs={12} sm={12} md={12} lg={6}>   {/* 手機2欄、桌面4欄 */}
```

## 7. Empty States & Loading

| 狀態 | 呈現方式 |
|------|----------|
| 初次使用，尚無資料 | AntD `Empty` 加上「+ 新增第一筆帳單」的 CTA |

| API 載入中 | AntD `Spin`（表格骨架）/ `Skeleton` |
| API 錯誤 | AntD `Alert` type="error" 顯示 message |
